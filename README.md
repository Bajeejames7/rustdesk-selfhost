# James's private RustDesk package

This package configures the official RustDesk OSS ID/signaling server (`hbbs`) and relay (`hbbr`) so James can view/control his own Samsung S23 and Windows PC over the internet through a relay he controls. Both containers use the pinned `rustdesk/rustdesk-server:1.1.15` image and persist their identity under `./data`. Follow [setup.md](setup.md), review the optional home-router commands in [mikrotik-portforward.rsc](mikrotik-portforward.rsc), then follow [client-setup.md](client-setup.md). These are config and instructions only: nothing was deployed, no router changes were applied, and no secrets are included. Normal on-device consent and the active screen-share/session indicator remain intact; no hidden-session behavior is added. The `.rsc` filename follows the explicit request; TASK.md's `.rize` spelling is treated as a typo.

For James's network, a mesh VPN alternative such as **Tailscale** avoids inbound port forwarding and CGNAT problems. Install Tailscale on the S23 and Windows PC, sign them into the same tailnet, and allow the required peer traffic in tailnet policy and local firewalls. In RustDesk enable direct IP access on the device being controlled, then connect to that device's Tailscale IP (default RustDesk direct-access port TCP 21118), authenticate with its locally configured password, and grant Android screen capture normally. This uses the tailnet address instead of public RustDesk ID discovery and needs no public RustDesk server. Prefer direct IP connections for this alternative; do not assume leaving clients at default public ID-server settings makes ID-based sessions private. Tailscale may use its own coordination and DERP relay infrastructure when direct peer connectivity fails, so this alternative does not meet a strict no-third-party-infrastructure requirement. It is optional; the primary package uses James's self-hosted RustDesk server. See [Tailscale connectivity](https://tailscale.com/kb/1257/connection-types) and [RustDesk direct IP settings](https://rustdesk.com/docs/en/client/).
